# Glossary

**Symlink** — This is a symbolic link of a program. You can make changes in the original and it will change the original, but not the other way around.

**Staging area** — This part is the intermediate part of the cycle. I select the changes i want to add to the commit, not all changes i made to the file or app

**Fragment** — The fragment is a browser-side concept, is part of the URL. it comes after #
