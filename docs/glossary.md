# Glossary

**Symlink** — This is a symbolic link, like a shadow you place somewhere else of an original file or folder. If you change something in the shadow, it will make changes in the original. If you delete the pointer it will not erase the real file/folder, as it is only an advanced shorcut not the real deal.

**Staging area** — This part is the intermediate part of the cycle. I select the changes i want to add to the commit, not all changes i made to the file or app.
